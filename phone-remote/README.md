# 手机端：大眼橙C5 Ultra蓝牙遥控器（phone-remote）

装在手机上的遥控应用。以蓝牙键盘 + 鼠标的身份连接投影仪，发送遥控按键。
基础按键（方向、确认、返回、主页、音量等）不需要投影仪端安装任何东西；
投影功能（对焦、梯形、游戏模式、亮度等）需要投影仪上装好并启用 [对焦助手](../projector-helper/)。

- 包名：`dev.imeiyou.projectorremote`
- 最低系统：Android 12
- 手机系统必须支持蓝牙 HID Device 功能。大多数 Android 12+ 手机支持，但少数厂商在系统里关闭了它，这种情况下"连接"会一直失败，本应用无法绕过
- 不依赖第三方库
- 网络权限只用于连接投影仪的网络 ADB，在后台恢复被系统停止的对焦助手（可选功能，见[下文](#guard)）

## 界面说明

**按键页**（从上到下）

- 顶部：连接状态、电源、连接
  - **电源**：按住时长分三段，防止误触：

    | 按住时长 | 按钮显示 | 松手后 |
    |---|---|---|
    | 1 秒内 | 电源 | 弹出关机菜单 |
    | 1～3 秒 | 松手取消（震动一次） | 什么都不发 |
    | 满 3 秒 | 正在关机（再震动一次） | 立即直接关机，不用等松手 |

    短按 / 长按由手机判断后再发给投影仪，不受蓝牙延迟影响
- 设置、主页
- 投影功能：深度对焦、自动梯形、手动梯形、画面尺寸、画面位移、游戏模式、MEMC、亮度
  - **MEMC**：点开后从底部弹出面板，可选 关 / 1 低 / 2 中 / 3 高，选中后面板自动收起。开启任一档位会自动关闭游戏模式
  - **亮度**：点开后从底部弹出面板，有亮度 −/+（每次 ±5，按住连续调节）和预设档位 30/50/70/85/100。
    手机无法读取投影仪当前亮度，实际数值以投影仪上弹出的提示为准
- 音量 −、静音、音量 +（音量键按住连续调节）
- 返回、菜单
- 圆形方向键：放在最下面方便拇指操作，大小随屏幕剩余高度自动调整（最大直径 280dp）

**触控板页**

- 单指滑动移动光标，轻点为点击，双指上下滑动为滚动
- 光标慢移精细、快划走得远。整体觉得太快或太慢，可以调投影仪的指针速度（-7 最慢，7 最快，默认 0），立即生效：

  ```bat
  adb shell settings put system pointer_speed -2
  ```
- 底部：返回、主页、确认

**手机音量键**：连接投影仪后，手机侧边的音量键会改为调节投影仪音量；未连接时保持手机原有功能。

## 按键编码

| 按键 | 发送的 HID 编码 | 投影仪上得到 | 发送方式 |
|---|---|---|---|

| 菜单 | 键盘 0x65 | MENU | 单击 |

| 电源 | 键盘 0x66 | POWER | 手机判断：短按发送 0.15 秒；按满 3 秒发送至少 3 秒；中间段不发送 |
| 音量 +/− | 键盘 0x80/0x81 | VOLUME_UP/DOWN | 按住 |

| MEMC 关 / 低 / 中 / 高 | 键盘 Alt + 0x23…0x26（Alt+6…9） | 对焦助手截获 | 单击 |

| 亮度 + / − | 键盘 0x3A / 0x3B（F1 / F2） | 对焦助手截获 | 按住 |
| 亮度预设 30/50/70/85/100 | 键盘 Alt + 0x1E…0x22（Alt+1…5） | 对焦助手截获 | 单击 |

## 编译与安装

1. 放在纯英文路径下，用 Android Studio 打开 `phone-remote` 文件夹。
2. 如果提示 Gradle JVM 版本不兼容，选 **Use JVM 21**。
3. **Build → Build App Bundle(s) / APK(s) → Build APK(s)**，生成
   `app/build/outputs/apk/debug/app-debug.apk`，拷到手机上安装。

## 首次连接

### 连接前的准备

1. **关闭其他蓝牙键盘/鼠标类应用。** 同一时间只能有一个应用以蓝牙键盘身份工作，
   其他蓝牙键盘/鼠标模拟应用如果还在后台，本应用会注册失败。
2. **如果手机以前和投影仪配对过，必须先删除配对。** 投影仪会缓存每台蓝牙设备"是什么样的键盘鼠标"（HID 描述符）。
   手机之前用别的应用或本应用的旧版本配对过，投影仪记住的是旧格式，按键会错乱
   （例如主页变成鼠标左键、静音变成返回）。
   - 投影仪：蓝牙设置里删除这台手机；
   - 手机：蓝牙设置里删除投影仪。

### 配对

1. 打开本应用，**长按右上角的"连接"**，选 **"让手机可被发现（首次配对用）"** ，
   允许系统的提示。手机会在 120 秒内可被搜索到。
2. 在投影仪的蓝牙设置里搜索设备，选中这台手机配对。
3. 配对成功后，投影仪会主动连上手机，顶部状态变为 **已连接：投影仪名称**，
   应用会自动记住这台投影仪。

### 以后使用

- 打开应用会**自动连接**上次的投影仪；也可以短按"连接"手动连接。
- 连接由**后台常驻服务**保持：切到别的应用、锁屏、划掉界面都不会断开。通知栏会有一条常驻通知显示连接状态。
- 投影仪关机后，服务继续等待；投影仪再开机时会主动连回手机，状态显示"等待投影仪连接…"。
- 要彻底断开：点应用里的"断开"，或通知栏里的"断开"。
- 长按"连接"可以重新选择投影仪。

### 可选：防止投影仪弹出音乐界面

手机连上投影仪时，投影仪可能把手机当成音乐来源，弹出蓝牙音乐界面。可以用 adb 关掉这台手机的音频连接。
**每次重新配对后这个设置会被重置**，需要再执行一次（查蓝牙地址、确认和恢复的方法见 [常见问题](../README.md#a2dp)）：

```bat
adb shell settings put global bluetooth_a2dp_src_priority_<手机蓝牙地址> 0
```

## 对焦助手自动恢复（网络 ADB）

投影仪系统在切换应用时（例如切到 HDMI）会强行停止对焦助手，它自己无法恢复（原因见[常见问题](../README.md#guard)）。
设置好之后，手机会通过网络 ADB 在后台把它恢复：把它加回无障碍服务清单，由系统重新启动。不打开任何界面，不影响正在播放的内容。

### 前提

- 手机和投影仪连在**同一个 WiFi**（不需要能上网）。手机没连 WiFi 时无法恢复，这时可以在投影仪上打开一次"对焦助手"。
- 投影仪的网络 ADB 开着，并且重启后仍然有效：

  ```bat
  adb shell getprop persist.adb.tcp.port
  ```

  输出 `5555` 即可。`adb tcpip 5555` 开启的网络 ADB 重启后会失效；有的固件在开发者选项里有"网络调试"开关。
- 建议在路由器里给投影仪绑定固定 IP，否则 IP 变了要重新填写。投影仪 IP 可以这样查：

  ```bat
  adb shell ip addr show wlan0
  ```

### 首次设置

1. 长按顶部的连接状态文字，打开调试面板，滑到"对焦助手自动恢复"。
2. 填入投影仪 IP，点 **"保存 IP 并授权（首次使用）"**。
3. 投影仪弹出"允许 USB 调试吗？"：用手机的方向键勾选 **"一律允许"** 后确认。对话框里的密钥指纹应与调试面板上显示的一致。
4. 面板显示"授权成功"和对焦助手的当前状态即完成。

### 什么时候检查

| 时机 | 说明 |
|---|---|
| 手机通过蓝牙连上投影仪 | 后台检查一次，不影响按键 |
| 按需要对焦助手的键之前 | 对焦、梯形、画面尺寸/位移、游戏模式、MEMC、亮度。5 秒内确认过就跳过 |
| 调试面板"立即检查并恢复" | 手动 |

- 对焦助手被停止后按的第一个投影功能键会慢 1～2 秒（先恢复再发送），不会丢。
- 方向键、音量等普通按键从不检查。
- 连不上、未授权、手机没连 WiFi 时，按键照常发送，接下来 15 秒内不再检查，避免每次按键都卡住。
- 恢复或出错时，按键页顶部会显示一行提示。

### 提示信息

| 提示 | 含义 / 处理 |
|---|---|
| 对焦助手被系统停止过，已在后台恢复 | 正常工作 |
| 对焦助手没有运行，已在后台重新启动 | 正常工作（在清单里但没运行，已移除再加回） |
| 投影仪刚开机，对焦助手可能还在启动 | 开机 90 秒内不做重新绑定，稍后会自动正常 |
| 投影仪还没有授权这台手机 | 在调试面板里重新点"授权"；手机重装或清除数据后密钥会变，需要重新授权 |
| 连不上投影仪（IP:5555） | 确认同一个 WiFi、IP 没变、网络 ADB 开着；路由器的"AP 隔离/客户端隔离"会阻止手机访问投影仪 |
| 手机没有连接 WiFi | 连上 WiFi 即可 |
| 投影仪上没有安装对焦助手 | 先安装 [对焦助手](../projector-helper/) |

### 安全说明

- 网络 ADB 开着时，同一局域网里的设备都可以尝试连接投影仪；只有在投影仪上点过"允许"的密钥才能真正连上（新设备会弹出确认框）。
- 手机的 ADB 密钥只保存在本应用的私有存储里。卸载应用或清除数据会删除它。
- 不想用时，在调试面板里取消勾选"按投影功能键前自动检查并恢复"。

长按顶部的连接状态文字，打开调试面板：

- **震动方式：** 不同手机对应用震动的限制不同。逐个点"试：…"，哪个能震就停在哪个，电源键会改用这种方式（会记住）。
- **电源测试模式：** 勾选后，电源按满 3 秒只显示"测试：关机"，不真正关机，方便测试分段。不保存，重新打开应用后自动关闭。
- **对焦助手自动恢复：** 投影仪 IP、首次授权、立即检查、自动检查开关，见[上文](#guard)。

## 已知限制

- 首次连接时会同时申请"附近的设备"和"通知"两项权限。拒绝通知权限不影响连接，只是看不到常驻通知。
- 如果系统的电池优化把应用强行停止，连接会断开，需要重新打开应用。部分国产系统需要在应用的电池设置里改为"不限制"或"允许后台运行"。
- 手机无法读取投影仪的当前状态（亮度、游戏模式等），实际状态以投影仪上的提示为准。
- 更换了应用版本且 HID 描述符有变化时（见 `HidDescriptor.java`），需要两边删除配对后重新配对。
- 连接后，手机侧边音量键会控制投影仪音量；断开后恢复控制手机音量。
