# 手机端：大眼橙C5 Ultra蓝牙遥控器（phone-remote）

装在手机上的遥控应用。以蓝牙键盘 + 鼠标的身份连接投影仪，发送遥控按键。
基础按键（方向、确认、返回、主页、音量等）不需要投影仪端安装任何东西；
投影功能（对焦、梯形、游戏模式、亮度等）需要投影仪上装好并启用 [对焦助手](../projector-helper/)。

- 包名：`dev.imeiyou.projectorremote`
- 最低系统：Android 12
- 手机系统必须支持蓝牙 HID Device 功能。大多数 Android 12+ 手机支持，但少数厂商在系统里关闭了它，这种情况下"连接"会一直失败，本应用无法绕过
- 不依赖第三方库

## 界面说明

**按键页**（从上到下）

- 顶部：连接状态、电源、连接。电源和原装遥控器一样：**短按弹出关机菜单，长按直接关机**
- 设置、主页
- 投影功能：深度对焦、自动梯形、手动梯形、画面尺寸、画面位移、游戏模式、MEMC、亮度
  - **亮度**：点开后从底部弹出面板，有亮度 −/+（每次 ±5，按住连续调节）和预设档位 30/50/70/85/100。
    手机无法读取投影仪当前亮度，实际数值以投影仪上弹出的提示为准
- 音量 −、静音、音量 +（音量键按住连续调节）
- 返回、菜单
- 圆形方向键：放在最下面方便拇指操作，大小随屏幕剩余高度自动调整（最大直径 280dp）

**触控板页**

- 单指滑动移动光标，轻点为点击，双指上下滑动为滚动
- 底部：返回、主页、确认

**手机音量键**：连接投影仪后，手机侧边的音量键会改为调节投影仪音量；未连接时保持手机原有功能。

## 按键编码

|---|---|---|---|

| 确认 | 键盘 0x28 | DPAD_CENTER | 按住 |
| 返回 | 消费者 0x0224 | BACK | 单击 |

| 菜单 | 键盘 0x65 | MENU | 单击 |

| 电源 | 键盘 0x66 | POWER | 按住（短按/长按由投影仪判断） |

## 编译与安装

1. 放在纯英文路径下，用 Android Studio 打开 `phone-remote` 文件夹。
2. 如果提示 Gradle JVM 版本不兼容，选 **Use JVM 21**。
3. **Build → Build App Bundle(s) / APK(s) → Build APK(s)**，生成
   `app/build/outputs/apk/debug/app-debug.apk`，拷到手机上安装。

## 首次连接

### 连接前的准备

1. **关闭其他蓝牙键盘/鼠标类应用。** 同一时间只能有一个应用以蓝牙键盘身份工作，
   其他蓝牙键盘/鼠标模拟应用如果还在后台，本应用会注册失败。
2. **如果手机以前和投影仪配对过，必须先删除配对。** 投影仪会缓存每台蓝牙设备"是什么样的键盘鼠标"（HID 描述符）。
   手机之前用别的应用或本应用的旧版本配对过，投影仪记住的是旧格式，按键会错乱
   （例如主页变成鼠标左键、静音变成返回）。
   - 投影仪：蓝牙设置里删除这台手机；
   - 手机：蓝牙设置里删除投影仪。

### 配对

1. 打开本应用，**长按右上角的"连接"**，选 **"让手机可被发现（首次配对用）"** ，
   允许系统的提示。手机会在 120 秒内可被搜索到。
2. 在投影仪的蓝牙设置里搜索设备，选中这台手机配对。
3. 配对成功后，投影仪会主动连上手机，顶部状态变为 **已连接：投影仪名称**，
   应用会自动记住这台投影仪。

### 以后使用

- 打开应用会**自动连接**上次的投影仪；也可以短按"连接"手动连接。
- 连接由**后台常驻服务**保持：切到别的应用、锁屏、划掉界面都不会断开。通知栏会有一条常驻通知显示连接状态。
- 投影仪关机后，服务继续等待；投影仪再开机时会主动连回手机，状态显示"等待投影仪连接…"。
- 要彻底断开：点应用里的"断开"，或通知栏里的"断开"。
- 长按"连接"可以重新选择投影仪。

### 可选：防止投影仪弹出音乐界面

手机连上投影仪时，投影仪可能把手机当成音乐来源，弹出蓝牙音乐界面。可以用 adb 关掉这台手机的音频连接。
**每次重新配对后这个设置会被重置**，需要再执行一次：

```bat
adb shell settings put global bluetooth_a2dp_src_priority_<手机蓝牙地址> 0
```

## 已知限制

- 首次连接时会同时申请"附近的设备"和"通知"两项权限。拒绝通知权限不影响连接，只是看不到常驻通知。
- 如果系统的电池优化把应用强行停止，连接会断开，需要重新打开应用。部分国产系统需要在应用的电池设置里改为"不限制"或"允许后台运行"。
- 手机无法读取投影仪的当前状态（亮度、游戏模式等），实际状态以投影仪上的提示为准。
- 更换了应用版本且 HID 描述符有变化时（见 `HidDescriptor.java`），需要两边删除配对后重新配对。
- 连接后，手机侧边音量键会控制投影仪音量；断开后恢复控制手机音量。
